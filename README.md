# RACING PROJECT

Game street racing 3D ringan berbasis HTML, CSS, JavaScript, dan Three.js.

## Menjalankan lewat GitHub Pages
1. Buat repository publik bernama `RACING-PROJECT`.
2. Upload `index.html` ke bagian utama (root) repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`, lalu Save.
6. Tunggu proses selesai. Alamat game: `https://USERNAME.github.io/RACING-PROJECT/`.

Game memerlukan koneksi internet untuk memuat library Three.js dari CDN. Kontrol layar sentuh dan keyboard tersedia.
